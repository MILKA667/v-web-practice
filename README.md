## Практика 2
В рамках практики №2 была реализована работа с React.js: данные передаются через Context, реализованы корзина и функционал лайков для товаров, а также организован поиск по странице, для организации навигации между страницами использован React Router.
### 📦 Установка и запуск
1. Клонируйте репозиторий
```bash
git clone https://github.com/MILKA667/v-web-practice.git
cd prac-2
```
2. Запуск
```bash
# Установите зависимости
npm install
# Запустите
npm run dev
```
